- **Mathematics for ML** — linear algebra, calculus, probability and statistics
- **Classical Machine Learning** — regression, classification, clustering, model evaluation
- **Deep Learning** — neural networks, CNNs, RNNs and modern architectures
- **MLOps** — experiment tracking, model deployment, monitoring and pipelines

## ⚙️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/RithikRaj129/ml-mastery.git
cd ml-mastery
```

### 2. Create a virtual environment (recommended)
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the notebooks
```bash
jupyter notebook
```

**Requirements:** Python 3.10 or later. All code has been tested with the library versions listed in `requirements.txt`.
